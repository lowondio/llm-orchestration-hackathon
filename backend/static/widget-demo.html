🤖 AI Widget Demo

Welcome to the AI Chat Widget Demo

This page demonstrates the embeddable AI chat widget. Look for the chat button in the bottom-right corner of your screen!

Click the button to open the chat interface and start a conversation with the AI assistant. Your conversation history will be saved in your browser's local storage, so you can refresh the page and continue where you left off.

📋 How to add this widget to your website:

  1. Create and deploy your AI agent in the graph builder
  2. Select the trigger node and choose "Website Widget" as the trigger type
  3. Copy the embed code from the property panel
  4. Paste the code before the closing </body> tag on your website
  5. That's it! The widget will appear automatically
